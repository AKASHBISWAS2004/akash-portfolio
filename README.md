# Akash Kumar Biswas — Personal Portfolio

A responsive, static HTML/CSS/JavaScript portfolio designed for free deployment on Vercel.

## Before publishing
1. Open `index.html`.
2. In the Contact section, replace `your-email@example.com` with the email address you want to make public.
3. Add your real LinkedIn and GitHub profile URLs.
4. Replace the two project placeholder cards with projects you have actually completed.
5. If you want a real profile photo, add it to `assets/` and replace the initials avatar in `index.html`.

## Preview locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy free with GitHub + Vercel
1. Create a GitHub account at https://github.com/ if you do not already have one.
2. Create a new public or private repository, e.g. `akash-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Sign in at https://vercel.com/ using GitHub.
5. Choose **Add New → Project**, import `akash-portfolio`, and click **Deploy**.
6. Vercel will provide a `*.vercel.app` URL.

## Vercel settings
This is a plain static website. Framework Preset: **Other**. Build Command: leave blank. Output Directory: leave blank (or `.` if the dashboard requires a value). No environment variables are needed.

## Privacy
Your home address and phone number are intentionally not published in this starter portfolio. Only add contact details you are comfortable making public.
